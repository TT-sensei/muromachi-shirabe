# 室町しらべ｜今に伝わる室町文化

小学6年社会科「今に伝わる室町文化と人々のくらし」の調べ学習用Webサイトです。

室町時代に生まれたり、広まったりした文化の中から、今にも残っているものを探します。

## 学習の流れ

「見る → 気づく → 調べる → ノートにまとめる → 今とのつながりを考える」

「室町時代の文化で、今にも残っているものは何だろう？」
という問いをもとに、気になったテーマを選んで調べます。

最後は、

「なぜ、室町時代の文化が今まで残っているのだろう？」

という問いにつなげます。

## 調べるテーマ

### 今のくらしにつながる文化
- 書院造
- 水墨画・雪舟
- 枯山水
- 能・狂言
- 茶の湯
- いけばな
- 祇園祭

### 室町の人々のくらしと文化
- おとぎ草子・昔話
- 市・商売・ものづくり

各テーマに、厳選した外部資料へのリンク、「ノートにメモ」「調べるポイント」を用意しています。

## 資料の使い方

外部の博物館・文化施設・教育サイトなどを開いて調べます。

資料の文章をそのまま写すのではなく、

- 何が分かったか
- おもしろいと思ったこと
- 今の生活とどこがつながっているか
- なぜ今まで残っていると思うか

を自分の言葉でノートに残すことを大切にしています。
